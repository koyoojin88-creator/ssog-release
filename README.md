# S.S.O.G

** Smart & Simple Office Gadget** — 사내 업무용 메모 프로그램입니다.

이 저장소는 **설치파일을 배포하기 위한 곳**이며, 소스 코드는 들어 있지 않습니다.

---

## 내려받기

### [⬇ 최신 버전 받기](../../releases/latest)

| 파일 | 언제 쓰나요 |
|---|---|
| `SSOG-Setup-x.x.x.exe` | **보통은 이것.** 두 번 클릭하면 설치됩니다 |
| `SSOG-Portable-x.x.x.exe` | 설치 권한이 없거나 USB로 쓰고 싶을 때 |

---

## 설치 방법 (2분)

1. 위에서 `SSOG-Setup-x.x.x.exe` 를 내려받아 **두 번 클릭**합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]** 을 누릅니다.
   (사내에서 만든 프로그램이라 뜨는 안내입니다. 문제 없습니다.)
3. **[다음] → [설치] → [마침]**
4. 바탕화면에 **S.S.O.G** 아이콘이 생깁니다.

**관리자 권한은 필요하지 않습니다.**

---

## 이미 쓰고 계신다면

**따로 받으실 필요 없습니다.**
프로그램이 새 버전을 알아서 알려주고, **[⚙ 설정] → 업데이트** 에서 버튼 한 번으로 설치됩니다.
**메모는 그대로 유지됩니다.**

---

## 주요 기능

- 바탕화면에 붙이는 **포스트잇** — 크기 조절, 제목만 남기고 접기, 항상 위
- **전체 메모 검색** — 결과에서 [이동]을 누르면 그 낱말 자리로 바로 이동
- **사내망 공유** — 서버 없이 PC끼리 직접, 양쪽에서 수정
- **일정 알림**, **오늘 할 일**(프랭클린 방식)
- **파일·이미지 첨부**, **메모 잠금**, **서식**, **글자 꾸미기**
- 메모는 **직접 지우기 전까지 사라지지 않습니다** (휴지통 + 매일 자동 백업)

---

## 공유 기능을 쓰려면

사내 방화벽에서 **TCP 45671**, **UDP 45670** 허용이 필요합니다. 전산팀에 요청해 주세요.
